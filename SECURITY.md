# Security policy

Use active network tools only on assets within an authorized assessment scope. Examples use loopback or documentation addresses. Imports and `--help` do not scan, capture, change interfaces or start listeners.

Do not commit real screenshots, PCAPs, credentials or customer information. The screenshot tool writes locally and does not upload. Header inspection does not contact a geolocation service or follow redirects.

Report vulnerabilities using GitHub private reporting if enabled; otherwise open a minimal issue asking for a private channel without disclosing sensitive details. No private endpoint or response SLA is currently configured.
